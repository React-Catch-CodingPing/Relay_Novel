# Relay Novel Web Application 📚

Relay Novel은 Firebase와 React를 기반으로 한 릴레이 소설 웹 애플리케이션입니다. 이 프로젝트는 4인 팀이 협력하여 개발했으며, 사용자가 릴레이 방식으로 소설을 작성하고, 공유 및 관리할 수 있는 플랫폼을 제공합니다. 로그인한 사용자만 이용 가능한 고유한 기능을 포함하고, 커뮤니티와 상호작용을 강화한 웹 애플리케이션입니다.

---

## 📝 주요 기능

### 1. 회원가입 및 로그인
- **Firebase Authentication**을 사용하여 이메일과 비밀번호로 안전하게 회원가입 및 로그인.
- 로그인한 사용자만 소설 작성, 커뮤니티 참여 및 좋아요, 추천 기능 사용 가능.
- **Admin 계정 기능**:
   - 이름과 닉네임이 `admin`인 경우 관리자 계정으로 가입.
   - 관리자 계정은 모든 유저들이 작성한 신고글을 확인 할 수 있음.

---

### 2. 소설 작성 및 관리
- 릴레이 방식으로 소설 작성: 사용자가 한 번에 한 줄씩 소설을 이어갈 수 있음.
- **100줄 제한 기능**: 100줄 제한이 설정된 소설은 100줄이 넘어갈 경우 추가 작성 제한.
- 각 줄의 작성자는 **작성자명**과 함께 기록되며, 작성자만 수정 및 삭제 가능.
- 소설은 **Firebase Firestore**에 저장되며 언제든 불러오기 및 이어쓰기 가능.

---

### 3. 커뮤니티 기능
- 사용자 간 소통을 위한 커뮤니티 페이지 제공.
- 게시글 작성, 수정, 삭제 가능.
- **댓글 기능**: 커뮤니티 게시글에 댓글 작성, 수정, 삭제 가능.
- 게시글 및 댓글 작성자는 **작성자명**과 함께 기록.

---

### 4. 투표 및 추천 기능
- 소설 및 저자에 대해 좋아요(❤️)나 추천(👍) 버튼 제공.
- 좋아요와 추천 데이터를 기반으로 소설 및 저자들의 인기도를 분석.

---

### 5. 장르별 소설 필터링
- 사용자는 `로맨스`, `미스터리`, `코믹`, `액션` 등 장르를 선택해 소설 탐색 가능.
- `조회순`, `좋아요순`, `추천순` 등 정렬 옵션 제공.
- 필터링 및 정렬된 소설 리스트는 직관적인 UI로 제공.

---

### 6. 프로필 페이지
- 사용자 활동 요약 페이지 제공:
   - 작성한 소설, 좋아요 및 추천한 소설 목록.
   - 커뮤니티 게시글 및 댓글 기록.
- 사용자 프로필 정보: 닉네임, 프로필 이미지, 활동 내역.

---

### 7. 조회수 및 참여수 기록
- 각 소설 및 게시글은 조회수와 참여수를 기록하여 데이터 기반의 분석 제공.
- 소설 줄 수, 참여 사용자 수를 통해 인기 작품 랭킹 노출.

---

### 8. 실시간 데이터 동기화
- 실시간으로 소설 및 커뮤니티 게시글의 변경사항 반영.
- 여러 사용자가 동시에 참여해도 최신 상태 유지.

---

## 🎨 주요 화면 구성

1. **홈 화면**
   - 인기 소설, 새로운 소설, 커뮤니티 핫 게시글을 한눈에 볼 수 있는 대시보드.
2. **커뮤니티 페이지**
   - 게시글 목록, 게시글 디테일, 댓글 기능 제공.
3. **명예의 전당 페이지**
   - 참여율을 기반으로 저자들을 나열, 탑 3를 볼 수 있는 페이지.
4. **저자별 모아보기 페이지**
   - 모든 저자 확인 가능, 이름으로 검색 가능한 페이지.
5. **장르 페이지**
   - 장르 및 정렬 옵션을 선택해 원하는 소설을 탐색할 수 있는 페이지.
6. **소설 디테일 페이지**
   - 소설 본문, 작성된 줄, 좋아요 및 추천 버튼 제공.
7. **소설 시작 페이지**
   - 소설 커버 이미지, 제목, 첫 줄 내용 입력하여 원하는 소설을 시작 할 수 있는 페이지.
8. **창작 가이드 페이지**
   - 처음으로 릴레이 소설을 시작하는 이들에게 가이들을 제공하는 페이지.
9. **프로필 페이지**
   - 사용자의 활동과 기여도를 확인할 수 있는 페이지.

## 🛠 사용 기술 스택

### **Frontend**
- **React**: UI 구현 및 컴포넌트 기반 개발.
- **React Router**: 페이지 라우팅.
- **Styled Components**: CSS-in-JS 스타일링.
- **Material-UI**: UI 컴포넌트 라이브러리.
- **Axios**: API 호출 및 데이터 통신.
- **React Hook Form**: 사용자 입력 데이터 처리.
- **Framer Motion**: 애니메이션 및 전환 효과.

### **Backend**
- **Firebase Authentication**: 사용자 인증 및 권한 관리.
- **Firebase Firestore**: 실시간 데이터베이스로 소설, 게시글, 댓글, 사용자 정보 저장.
- **Firebase Hosting**: 애플리케이션 배포 및 호스팅.
- **Firebase Storage**: 사용자 프로필 이미지 및 소설 커버 이미지 저장.

## 🛠️ 프로젝트 실행 메뉴얼

박승현 교수님께 드리는 프로젝트 실행 안내입니다. 😊

1. **프로젝트 클론 또는 다운로드**
   - GitHub 저장소에서 프로젝트를 클론 받으시거나 제공드린 압축 파일을 다운로드합니다.

2. **환경 변수 설정**
   - 제공드린 `.env` 파일을 **프로젝트 루트 디렉토리**(소문자 `relay-novel` 폴더) 아래에 넣어주세요.

3. **필요 패키지 설치**
   - 프로젝트 루트 폴더에서 터미널을 열고 아래 명령어를 실행해 프로젝트 의존성을 설치합니다:
     ```bash
     npm install
     ```

4. **프로젝트 실행**
   - 동일한 위치에서 아래 명령어를 실행하여 애플리케이션을 실행합니다:
     ```bash
     npm start
     ```

5. **애플리케이션 접속**
   - 프로젝트가 실행되면 웹 브라우저가 자동으로 열리며, `http://localhost:3000`에서 Relay Novel 애플리케이션을 확인하실 수 있습니다.
